# WaveQA Releases

Download the latest version of **WaveQA** — the AI-powered mobile automation testing platform.

## Download

Find the latest release on the [Releases page](../../releases).

| Platform | File |
|----------|------|
| macOS | `WaveQA-x.x.x-mac.zip` |
| Windows | `WaveQA-Setup-x.x.x.exe` |
| Linux | `WaveQA-x.x.x.AppImage` |

## Installation

### macOS
Unzip and drag **WaveQA.app** to your Applications folder.

### Windows
Run the `.exe` installer.

### Linux
Make the `.AppImage` executable and run it:
```bash
chmod +x WaveQA-*.AppImage
./WaveQA-*.AppImage
```
